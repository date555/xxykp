# 向咸鱼开炮

独立本地浏览器游戏，所有玩法与代码在本目录从零实现。没有读取或复用此前几个游戏项目的设计或代码；仅使用远程资源工具下载的咸鱼之王原始资源，以及资源整理工具的图集格式知识和已有骨骼运行库。

## 启动

双击 `启动游戏.cmd`，按窗口提示访问 **http://127.0.0.1:4178**。需要已安装 Node.js；当前电脑已具备。运行游戏不需要安装依赖，不连接游戏账号或游戏服务器。

也可以在本目录运行：

```powershell
node server.mjs
```

请使用这个固定地址，浏览器本地存档按地址隔离。请勿直接双击 `index.html`，浏览器模块与骨骼资源需要本地 HTTP 服务。

## 部署为在线游戏

支持 Cloudflare Pages 和 GitHub Pages，玩家打开链接即可游玩。运行 `npm run build` 生成 `dist/`，不需要安装构建依赖；Cloudflare 使用 Git 连接或 Wrangler 上传，GitHub 的自动部署工作流已放在 `.github/workflows/deploy-pages.yml`。具体设置见 [部署指南](docs/部署指南.md)。本地游戏名、目录名和存档导出名已统一为“向咸鱼开炮”，旧存档继续兼容；线上换域名后可通过导出 / 导入迁移进度。

## 已实现

- 16:9 横屏游戏界面：全部操作收进画面内，支持等比缩放和全屏；玩具使用原版底座与进度圈显示冷却，图鉴 / 衣橱 / 首领和奇策使用原版卡框。皮肤普攻与技能可在游戏内试演。
- 左侧五个可交换阵位，武将朝右，右侧三路来袭；武将自动普攻，每第 5 次攻击改为自动技能。
- 郭嘉、周瑜、司马懿、甘宁、鲁肃、庞统、公孙瓒、张角、诸葛亮、甄姬、黄月英、夏侯渊、黄忠、张昭、陆绩、祝融夫人，并新增关羽、太史慈、吕布、华佗、孙策、贾诩、曹仁、姜维、孙坚、大乔、小乔，共 27 位武将。
- 原版 idle / attack / skill 骨骼动作、每位武将各自的普攻与技能弹道、原配置指定的命中特效，连同玩具与状态效果，连同皮肤和首领共 556 组骨骼资源。直线、飞行、抛物线、冲击、目标位置与中心范围特效分别处理；出手前摇和命中结算分离。
- 57 章共 570 关、114 个 Boss、9 种小怪。收录 112 套原版首领骨骼，保留 2 个旧静态首领；加入回春、坚壁等机制。按章节分页浏览，另有完整首领图鉴。
- 皮肤衣橱：114 套兼容外观（含默认外观，另有 87 套可切换外观），招募后免费穿戴。头像、立绘、武将动作、普攻与技能弹道同步切换，不加属性。营地支持姓名、皮肤、阵营、收集状态筛选。
- 本体必需动作、普攻 / 技能弹道、命中特效与 UI 都齐全才收录；不兼容项及原因见适配清单。运行时只加载当前阵容和当前章首领，切换时释放旧骨骼纹理。
- 每 3 关三选一：单将特质只影响卡面指定武将（多目标、连攻、减速、溅射）；全体属性是较小幅度加成（攻击 +10%、攻速 +8%、暴击率 +3% 等）。另有玩具、营地强化。
- 3 个手动玩具：冰镇啤酒、穿云箭、祖传大饼。各自播放正式配置指定的原版动画，按命中事件结算；冰冻、回血也使用原版骨骼，加速持续 6 秒并有光环提示。快捷键为 1 / 2 / 3。
- **招募、等级、星级与换装全部在局外进行**。出征阵容快照固定，战斗中禁止营地操作。
- 单抽、十连、10 次内保底新武将，重复武将转 8 碎片；150 级上限，30 星上限。
- 营地、武将详情和战场使用原版星级 UI：每 5 星换色，黄星 → 紫星 → 橙星 → 红星 → 皇冠 → 紫冠；升星碎片消耗取自原版 30 档配置。
- 结算、章节解锁、首通奖励、重复挑战、暂停、二倍速、本地存档、导入与导出。
- 兼容旧版八将、十六将存档，新增武将进入未招募状态，原有资源、等级、星级与关卡进度保留；新的吕布存档不会误触旧原型的改名迁移。

## 操作

1. 在战场点击武将或下方阵位来换将。交换已上阵武将会交换两个阵位。
2. 在“武将营地”使用金币和精铁升级，消耗同名碎片升星；点击“外观”打开衣橱。在“招贤馆”使用招募令。
3. 点击“开始出征”。前排阵位能更早攻击来敌，每个阵位优先照顾所在路线。
4. 适时释放玩具；每 3 关选择一项本局强化。空格可以暂停 / 继续。
5. 每章 10 关。胜利、失败或主动撤退都会结算已通过关卡；章节结束清空本局强化。

切到后台会自动暂停；刷新会放弃未结算战斗，已保存的营地进度保留。使用“设置与存档”导出备份后，可在其他浏览器导入。

## 重建美术（可选）

运行 `tools/rebuild-assets.ps1`。它先运行 `audit_content.py` 和 `prepare-content.py` 筛选并生成清单，再读取本工作区已有远程资源、Pillow 和骨骼图片拼合工具已有的 Pixi / Spine / esbuild，不下载网络资源。普通试玩不需要执行这个步骤。

运行库为 Pixi 6.5.10 与 pixi-spine 3.1.2（Spine 3.8）；对应许可证保留在 `vendor/`。

内容文档可用 `node tools/export-content-docs.mjs` 和 `node tools/export-design.mjs` 更新；资源散列检查使用 `node tools/verify-assets.mjs`。

原版动作与内置皮肤的 CPU 姿态检查：`node tools/verify-rigs.mjs`（使用已有骨骼工具运行库，不渲染纹理）。
