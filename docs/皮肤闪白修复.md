# 皮肤技能整屏闪白修复 · 2026-10-25

## 原因与复现

郭嘉「鱼」音绕梁（AvatarConf 10207）的技能引用链：

`AvatarConf 10207 → BulletConf 102071 (Position) → EffectConf 1607 → guojia7/guojia7_skill_hit`

原始 SkeletonConf / 骨骼数据的尺寸为 `0 × 0`。旧适配器用 `Math.max(1, meta.width/height)` 避免除零，再把位置特效缩放到 200 像素，因此实际缩放变成 **200 倍**。这个动画的真实可见几何范围约为 **2496 × 2573**，放大后覆盖整个战场。浏览器在技能演示 1.20 秒处实际复现白屏，见 `郭嘉闪白-修复前.jpg`。

这是原始尺寸缺失与本作缩放回退逻辑共同造成的问题；本次没有调整贴图或混合模式。

## 修复

- `src/spine-bounds.js` 在尺寸缺失、无穷或非正数时，按 60 fps 遍历实际播放动画，计算可见区域 / 网格附件的联合范围。跳过隐藏附件和不渲染的路径、碰撞框；包含缩放、旋转和网格变形。
- 测量覆盖整个动画，避免用空白首帧或尚未展开的特效来估算大小；额外留 5% 插值余量。
- `src/spine-runtime.js` 加载时缓存计算结果，弹道、范围特效、命中特效统一使用有效尺寸。已有效的源尺寸保持原本缩放；原文件和来源清单不被改写。
- 删除“尺寸缺失时按 1 像素缩放”的特效回退，非法缩放显式报错。
- 这 12 套皮肤都可以修复，全部保留。皮肤数仍为 114 套；普攻 / 技能引用、命中时间、伤害和局外养成规则未改动。
