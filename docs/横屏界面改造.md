# 横屏界面改造 · 2026-10-25

游戏现在使用 1440 × 810 的横屏画面，按窗口等比缩放；多余空间留边。导航、资源、营地耐久、暂停、倍速、阵容、玩具、章节与出征按钮都位于画面内部。主文档不滚动，图鉴、关卡与衣橱只在各自面板内滚动。

## 原版 UI 来源

从已下载的 3c7b0bfc39 资源包提取了 40 张 UI 图片，未重新绘制这些图片。原包、图集、裁切坐标、旋转与裁边偏移、九宫格元数据和 SHA-256 见 `landscape-ui-sources.json`。复现入口为 `tools/prepare-landscape-ui.py`，已纳入 `tools/rebuild-assets.ps1`。

正式客户端的 `UICompLordSkill.setWeaponProgress` 显示的是武器能量百分比；本作保留其底座与黄色进度圈，适配为冷却蓄满并显示剩余秒数。冷却取自实际战斗状态，不使用独立墙钟；暂停、奇策选择时冻结，倍速随战斗推进。可释放时亮起，等待出征、暂停、释放中与冷却状态由界面区分。圆环填充与亮起动画由 CSS 完成，玩具攻击演出继续使用已有原版骨骼。

这些是原版 UI 资源在网页中的横屏重排，并非移植完整 FairyGUI 面板逻辑。原版星级、武将弹道、养成消耗、关卡数与存档结构未修改。

## 游戏内面板

- 武将图鉴：原版金色 / 蓝色卡框、阵营图标、六档星级，保留姓名、皮肤、阵营和收集状态筛选。
- 衣橱：原版卡框；“试演普攻与技能”在游戏内打开演示面板，不再跳到新标签页；关闭后移除演示以停止运行。
- 首领图鉴：114 个首领使用原版红色图鉴卡框，关卡路线保留 57 章分页。
- 营地、招募、设置、布阵、战报、奇策与结算均在横屏边界内显示。战斗中继续锁定局外招募和养成。
- 右上角支持全屏 / 退出全屏，弹窗与游戏使用同一缩放比例。
