# 素材与动画来源

当前扩展：27 位武将、114 套外观、112 套首领骨骼，保留两个静态首领，共 114 个首领。完整武将、皮肤、首领名单与排除原因见 [武将皮肤与首领适配](武将皮肤与首领适配.md)。下方 16 将表为原默认阵容引用示例，完整 114 套关联以新清单为准。

## 独立开发范围

没有使用“咸鱼塔防”“咸鱼大领主”“咸鱼祖玛”等既有游戏的设计或代码。

来源只包括已下载的正式客户端资源、正式配置表、资源解析工具的 FairyGUI 图集格式知识，以及骨骼图片拼合工具已经安装的 Pixi / Spine 运行库。

## 普攻与技能不能只看文件名

本次采用以下正式配置关联链，来源为本地 `58b91ed6c8/关键配置JSON/58b91ed6c8`：

1. `level.json → AvatarConf`：确定武将 path、attackBullets、skillBullets、attackDamage、skillDamage。
2. `tower.json → BulletConf`：确定弹道类型、弹道特效 ID 与参数。
3. `tower.json → EffectConf`：确定 bundle、uri、缩放、播放速度与命中特效。
4. `tower.json → SkeletonConf`：核对 idle / attack / skill 动作、时长与出手时刻。
5. 对应资源包 import 里的 `sp.SkeletonData`：解析实际 atlas、纹理页和二进制或 JSON 骨骼。
6. 浏览器中实际解析 556 组骨骼，并抽样播放原版动作与各类特效；任一必需动作或资源加载失败，禁止开始出征并显示错误。

## 改造边界

- 骨骼、纹理、动画轨道来自原版；画面朝向、尺寸与场上运动范围适配横向塔防。
- 保留直线、飞行、抛物线、冲击、目标位置和中心范围特效类型，移动速度和线路长度按塔防场景适配。
- 原版出手时刻参与前摇计算，攻速强化会同步加快角色出手。伤害在前摇与飞行结束后结算，不在按下攻击时提前扣血。
- 每第五次攻击使用技能、技能伤害倍率、控场与养成数值为本游戏独立设计，不声称复现正式游戏的完整战斗规则。
- 局外升星 30 档消耗取自 `config.json → HeroStarSpend → 1.starSpend`；原始行保存在 `docs/source-values.json`。
- 资源版本与配置版本不同，已通过逐项实际文件解析检查所选 27 位武将、114 套外观的引用可用；没有把目录存在当作动画运行成功的证据。

## 玩具动画与朝向更新

三件玩具直接由 `language.json:WeaponConf.icon` 确认身份，沿 `bullets → tower.json:BulletConf.effect → EffectConf.bundle/uri → SkeletonConf` 提取原版动画，没有按名称猜测替代特效。

| 玩具 | WeaponConf | BulletConf | EffectConf | 原版骨骼 | 原始命中 / 时长 |
| --- | ---: | ---: | ---: | --- | --- |
| 冰镇啤酒 | 6 | 500005 | 4010 | battleEffect/axwq_pijiu/axwq_pijiu | 1.67 / 2.83 秒 |
| 穿云箭 | 1 | 500002 | 4007 | battleEffect/axwq_yzcyj/axwq_yzcyj | 1.47 / 2.67 秒 |
| 祖传大饼 | 5 | 500004 | 4009 | battleEffect/axwq_bing/axwq_bing | 2.00 / 2.83 秒 |

状态动画为 EffectConf 10001 → buff_frozen/buff_bingdong，以及 10003 → buff_recovery/buff_huixue。玩具与状态共 5 组，连同所有武将、皮肤及首领相关资源总计 556 组。原文件未修改，仅在塔防坐标中缩放和定位，玩具演出加速至 1.7 倍。

武将骨骼使用原始朝向（正 X 缩放）统一面向右侧；加载前的静态立绘做水平翻转以保持方向一致。浏览器已核对待机朝向、普攻与技能右向发射。
